### 0:00–0:15｜钩子

【停一秒，看评委】

一组数字。全球加密 API 市场，2025 年 **11 亿美元**，2026 年 **13 亿**，年增 **22%**。

同期，链上开发者提交量跌了 **75%**，只剩 **6 万 7 千人**。

写代码的人在变少，买 API 的钱在变多。因为买 API 的人换了一茬——**以前是开发者，现在是 Agent。**

### 0:15–0:40｜问题

但 Agent 接不上链上的钱。三个卡点：

**不知道该调谁**——65 个上游，口径全不一样。
**不知道多少钱**——同样一次查询，便宜的 0.005 美元一千次，贵的 159 美元一千次。
**不知道能不能信**——同一个地址，三家给的标签不一样。

人可以查文档、比价格、交叉验证。**Agent 不能。**

### 0:40–1:05｜方案

我们做的就是这一层：**152 个工具、65 个上游，接一次 MCP 全通。**

每个工具带三个标注：**多少钱、能不能写、可信度多少。**

可信度不是我们自己说的——已经接上 **M8ven 的 MCP 信任评分**，和 **Mirko 的可信名单**。~~这两样，市面上做聚合的还没有。~~

### 1:05–1:55｜商业模型（这一段最重要，慢讲）

钱从三种人来：

**独立开发者，买省事**，19 美元一个月。
**小团队，买稳定**，79 美元。
**机构，买责任**——审计、SLA、私有化，299 起。

收入结构：**订阅七成，超量按次两成半，企业一成。**

单位经济我们算得很细。一次调用，我们收 **0.09 美分**。

**绿灯**工具——余额、价格、RPC——上游成本 0.0005 到 0.003 美分，**毛利 96%**。
**黄灯**——组合查询、安全检测——加权到 3 个 credit，**毛利 80%**。
**红灯**——Dune 查询、Nansen 标签——一次 16 到 50 美分，塞进订阅池必亏，所以我们**不打包，只做直采**。

### 1:55–2:35｜议价能力 = 商业可行性

这就是为什么**议价能力是这条生意的核心**。

我们已经和 **Dune、M8ven、Mirko** 建立了合作和议价通道。

Dune 目录价一次 **16 美分**，我们谈到 **11 美分**。按 15 美分卖，毛利 27%；
打包成"研究包"——**29 美元 100 次**，成本 11 美元，**毛利 62%**，而且客户是预付。

**议价三成，红区就从"不能卖"变成"能卖、能预付、能锁客"。**

红区不赚钱，**红区是获客**。利润在绿灯那 96% 里。

### 2:35–3:00｜目标与收尾

第一年目标：**150 个付费团队，年收入 15 万美元，毛利 75%。**

第三年：让上游自己把工具挂进我们的目录，我们**抽 15% 到 20%**——那才是"链上 AWS"真正开始的地方。

【停】

我们卖的不是数据。是**"不用跟 65 个供应商分别打交道"**。

## 5. "议价能力"该怎么讲（这是全场最值钱的一段）

很多团队会说"我们认识很多上游"。评委听到的是"没有壁垒"。所以必须讲成三段：

**第一段：量。** 我们不是零散调用，是把 65 家的零散需求汇成一份账单。对 Dune 来说，一个能带来持续 agent 查询的渠道，比一个自己写 SQL 的分析师更值钱。

**第二段：他们拿不到的流量。** agent 的调用是程序化的、7×24 的、可预测的——这正是上游最想要的负载，也是最难自己获得的。我们提供的是**分发**，不是转售。

**第三段：我们不做的事。** 我们不做数据再分发、不碰他们的品牌数据、不把 Smart Money 类端点对外卖。**这让议价变成合作而不是对抗。**

一句话收尾：**议价不是关系，是渠道价值换来的成本结构。**

## 6. 评委 Q&A（12 问，每问 20 秒内答完）

**Q1 你和 Alchemy 什么区别？**
他们是这一层的 EC2（160 个工具的 MCP，比多数人以为的强）。我们做它上面那张账单——把 65 家（含 Alchemy）并进同一套计价和同一条信任标准。单家上游永远不能说"别家用我更便宜"。

**Q2 技术壁垒是什么？**
不在代码，在标注：152 个工具的只读/可写、前置条件、失败语义、成本档位、可信分。这件事只能一家家磨，磨完还敢开源——因为开源才让上游愿意接。

**Q3 现在有付费用户吗？**
没有。但有三个可验证的东西：真实安装量、真实工具调用、以及 Dune / M8ven / Mirko 的议价通道。前两个证明有人用，第三个证明成本能谈。

**Q4 上游为什么不自己做，要让你抽成？**
已有 6 家自建 MCP（GoldRush、Nansen、Zerion、Tatum、QuickNode、CoinStats）。但它们只卖自己——**没有一家会告诉 agent"这笔该用别家"**。跨家判定天生需要一个中立层。

**Q5 议价凭什么？**
量 + agent 流量 + 我们不碰他们的再分发。这三条里，第二条最硬：程序化、7×24、可预测的负载，是他们自己拿不到的。

**Q6 毛利这么高，上游涨价怎么办？**
已经涨过一轮（Moralis \$49→\$149、Dune \$49→\$75）。我们的缓冲是两个：红灯不打包、BYO 用户成本为零。

**Q7 客户从哪来？**
GitHub 与文档站的自然流量 → 装 → 首次真实调用 → 付费。目标 CAC 低于 \$20，靠开源和 MCP 生态分发，不投广告。

**Q8 留存呢？**
目标月流失 < 8%。API 工具类一旦接进 CI 或 agent 工作流，替换成本很高——这是这类生意最好的地方。

**Q9 合规风险？**
以只读为主，不做托管、不做交易执行、不转售受限数据。红灯工具强制 BYO——用户自己的 key、自己的合同、自己的责任。

**Q10 大模型公司自己做怎么办？**
接 10 家可以，接 65 家带失败语义、带成本标注、带写入闸门的，不是模型公司愿意干的活。我们做的正是它们最不想做的部分。

**Q11 三年后壁垒还在吗？**
工具数量会被追上，判断力不会。路线是：能力层 → 账单层 → 市场层（抽 15–20%）→ 身份层（agent 的签名权）。**链上一切最终要签名，谁管签名谁就是这一层的 AWS。**

**Q12 最坏情况？**
上游全部自建 MCP 且语义标准化，我们退化成"可信目录 + 计费"，天花板降到 \$5M ARR——仍然是一门好生意，只是不再是平台。
