## 3. 过程中修掉的问题

| 问题 | 修法 |
| --- | --- |
| Uniswap V3 价格算错好几个数量级（精度换算写反） | 改为 `sqrt² × 10^d0 × 10^18 / (2^192 × 10^d1)`；并且**读不到 decimals 就报错**，不再静默按 18 处理 |
| 全零存储槽被当成"存在 proxiableUUID"，导致任何地址都被判可升级 | 槽值为 0 时返回 null |
| 字节码里随机出现 `ff`/`f4`/`f5` 就被标成风险 | 拆成 `opcodeHints` 单列，明确"也可能是常量数据，不能据此判定" |
| `anvil --silent` 不打印就绪信息，fork 一直等到超时 | 去掉 `--silent`，改为**主动轮询端口**双保险 |
| 复杂交易重放时 anvil 补状态慢，10s 拿不到回执 | 回执轮询放宽到 120 次 × 1s，并把 anvil stderr 带进错误信息 |
| 策展地址里有 3 个是错的（LooksRare 空代码、X2Y2 长度非法、Across 未部署） | 逐个用 `eth_getCode` 校验后移除/替换，并在调用处统一 `getAddress(lower)` |
| 公共 RPC 的 `eth_getLogs` 区块跨度限制从 1 万到不限不等 | 日志扫描改为**自适应收缩**：200k → 50k → 12.5k → 2k，实在不行才放弃该段并写入 warnings |

## 5. 未覆盖 / 已知边界

- `mempool_watch` 只反映单个节点视角，私有 mempool 与 relay bundle 看不到；工具在 note 里明确写了"没看到不等于没有"。
- `approval_scan` / `wallet_posture` 无 Etherscan key 时只扫最近区块窗口，覆盖范围写进 `scannedFromBlock` 与 warnings。
- `tx_call_tree` 在节点不支持 `debug_traceTransaction` 时降级为回执日志：能看到资产流向，看不到内部调用层级。
- `fork_replay` 依赖本机 `anvil` 与归档节点，复杂交易 30–60s，不适合放在同步请求里。
- `contract_posture` 是静态体检不是审计；逻辑漏洞与后门必须靠源码审计与模拟。

### 6.3 这一轮修掉的演示问题

| 问题 | 现象 | 修法 |
| --- | --- | --- |
| 主 RPC 拒绝历史日志 | 主网 `BCA_RPC_URL`（publicnode）对历史 `eth_getLogs` 返回 403，导致"列举登记"只回 0 条、"授权扫描"什么都扫不到——**看起来像工具没数据** | 新增 `logConfig()`：扫日志的路径优先走 `BCA_ARCHIVE_RPC_URL`，没配才退回主 RPC。改完同一条问法从"0 条"变成"23 个协议" |
| 模型把 from/to 弄反 | 复盘答案写成"发送方 0xBdb3… 调用了 0xBdb3…（自调用）" | 工具输出新增 `headline`（`0x5B43…EFd1 → 0xBdb3…47B6 · 成功 · gas …`），模型照抄后方向正确 |
| 模型自己算 gas 费 | 把 754124 gas 说成"约 2.63 ETH" | 输出新增 `gasCostWei` / `gasCostEth`，模型直接引用 → 0.00263 ETH |
| 缺 key 的工具被反复重试 | 复盘时为了解码 ABI 连续调用 6 次 `explorer_abi`，17 步、27s | 提示词约束"失败一次就停、同一工具最多两次"→ 降到 1 次调用、5 步 |
| 模型数链条数数错 | 同一条问法一次说 14 条链、一次说 16 条 | 输出新增 `chainCount` 与 `bountySummary`，提示词要求照抄 → 稳定 16 条 |
| 模型给地址贴身份 | 把某个地址说成"著名加密艺术家 Pak" | 提示词新增"没有标签就只说该地址" |
| 只读查询误走沙盒 | 一次 `arb_scan` 调到了 `mcp__bca-sandbox__` | 提示词新增"只读查询一律用主网工具，沙盒只用于发币发 NFT" |
| **file: 依赖不会重装** | `npm install` 报 `up to date`，dist 还是旧的（部署脚本静默失效） | 部署脚本改为先 `rm -rf node_modules/blockchain-anything` 再装；打包脚本 `upgrade.sh` 同时上传 `agent-pi.js` 与 `index.html`，避免下次再丢 |
