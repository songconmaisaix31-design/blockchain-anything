# BCA v1 实际验证

环境：Linux x64，Node v24.22.1。以已合并的 `9ef990a` 为基线，沿用户 D14 授权完成 v1 并合并。REA 参考范围见 [参考记录](../REA-REFERENCE.md)。

## 产品变化

- `find` 从全部真实工具中检索，可指定 MCP 读取实时工具及 Schema；保留 EVM 任务步骤。
- `init / build / test` 创建 Counter、OpenZeppelin ERC20 或执行已有 Foundry/Hardhat 工程。
- `connect` 将官方预设存入 `.bca/mcp.json`，后续 CLI/MCP 自动读取，保留不同配置。
- setup 将工作流入口写入所选客户端的项目指引，保留用户原文；安装后的终端可发现项目内 Foundry。
- prepare 支持 Git 源码构建，版本为 1.0.0，保持 private。

新增实现直接使用现有适配、官方组件、配置和执行函数，没有引入新依赖、调度器、数据库或评分设施。
