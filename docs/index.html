01 / QUICK START

一条命令，安装到项目

准备 Node 22.12+（22 LTS）或 Node 24 LTS、npm 和 Git，在目标项目目录执行：

npm exec --yes --package=git+https://github.com/songconmaisaix31-design/blockchain-anything.git#main -- bca setup --client both --install

首次下载和构建需要联网。包从 GitHub 源码安装，尚未发布到公共 npm。只使用一个客户端时，将 both 换为 codex 或 claude。

安装会生成项目 MCP 配置与工作流，保留现有条目并备份变更。随后在客户端信任该项目并批准 MCP。

从终端运行

node .bca/runtime/node_modules/blockchain-anything/dist/cli/main.js doctor

后续命令中的 bca 可替换为上面的 node …/cli/main.js。Windows x64 直接使用 PowerShell，无需修改全局 Bash 配置。镜像缺版本时，为 npm 命令加 --registry=https://registry.npmjs.org。完整安装说明 ↗

03 / PUBLIC TOKEN SECURITY

查询公开代币风险

GoPlus Token Security 公开 API 已实跑验证：Ethereum 与 Base 的代币查询成功，保留上游原始风险字段。无需 GoPlus 账户、API Key 或交易签名；这是只读 API 查询，不会发送链上交易。

已安装到目标项目

在完成项目安装后，从项目根目录执行：

node .bca/runtime/node_modules/blockchain-anything/dist/cli/main.js call goplus_token_security --input '{"chainId":"1","address":"0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48"}'

源码 checkout

在仓库根目录先执行 npm ci，再运行：

node dist/cli/main.js call goplus_token_security --input '{"chainId":"1","address":"0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48"}'

查看返回的 access、source、queriedAt，以及 response.result[address] 中的上游风险字段。字段缺失或空值只表示上游没有提供该项数据，不代表无风险，也不构成安全保证。

05 / KNOWN LIMITS

使用前了解这些边界

  • 账户型服务需要自行配置授权；工具目录不授予钱包或写入权限。
  • 公共链交易沿用宿主授权流程。内置一键部署仅面向明确批准的本地 Anvil 操作。
  • Windows / macOS 原生客户端 UI、公共测试网源码上传仍需分项验证。
  • 部分上游依赖仍有安全告警，详见依赖安全状态。
