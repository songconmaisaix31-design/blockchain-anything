# 靠近钱：把"链上赚钱"讲成一门可验证的生意

> 这是对外叙事主稿。技术细节与实测数据见 [MONEY-ADJACENT.md](./MONEY-ADJACENT.md)，工具清单见 [KEYS.md](./KEYS.md)。
> 一句话立场：**我们不卖"稳赚的机器人"，我们卖"把链上正在发生的事讲清楚、验明白"的能力。**

---

## 0. 开场：先承认一件没人愿意承认的事

提到"用区块链赚钱"，大多数人脑子里出现的是两种东西：一个是 K 线截图，一个是"我朋友跑了个机器人月入多少"。这两种都不能验证、不能复现、不能交付。

所以这份叙事从反面开始：

- **抢跑（三明治、狙击、貔貅盘）我们不做。** 不是因为道德洁癖，是因为它正在被私有 mempool 和聚合器系统性消灭，投入产出比在快速恶化，监管风险明确上升。
- **"看到价差就以为能套利"是这个领域最常见的错觉。** 今天实测：Uniswap V3 两个 WETH/USDC 池之间有 5.77 bps 价差，看起来有钱赚；扣掉两条腿 35 bps 手续费再扣 gas，$5 万本金净额 **−$146**。
- **真正持续有钱的地方，是"钱正在出问题"的地方。** 2025-11 Balancer V2 损失约 $1 亿，白帽追回约 $2100 万；2026-09 Magic Eden 旧授权事件抢救 23,155 个 NFT（$600 万）——**救不回来的是 660 WETH，救回来的是 NFT**。因为唯一的、可搬走的资产能被"抓住"，可替代的资产一旦转出就抓不住。

**这就是我们的定位：** 赚钱的动作发生在链上，钱出问题的地方也在链上。谁能在最短时间里把"发生了什么、损失多少、能不能救、救回来归谁"讲清楚，谁就靠近这笔钱。

## 1. 三句话讲清楚我们卖什么

**第一句：链上有三个"离钱最近"的岗位，它们用的是同一台引擎。**

| 岗位 | 谁付钱 | 一次多少 | 现在谁在做 |
| --- | --- | --- | --- |
| 白帽救援 | 协议（Safe Harbor 赏金） | 追回金额的 **10%**，上限 **$1M~$10M** | SEAL 生态白帽，已累计追回 **$150M+** |
| 复盘与归因 | 投研 / 合规 / 受害者 | 按项目或订阅 | EigenPhi、Nansen、Arkham（都不做自然语言解释） |
| 资金安全自检 | 用户自己 | 省下的就是赚的 | Revoke.cash 一类，只做撤销不做解释 |

它们共用同一条流水线：**fork 主网 → 重放 → 算 delta → 判断钱进谁的口袋**。区别只在最后一步。所以做一套引擎，三个岗位同时具备。

**第二句：法律是护城河，不是代码。**

SEAL 的 Whitehat Safe Harbor 是协议对"任何白帽"发出的**公开单方要约**——不需要认识人、不需要签约，按规则行动就受保护。覆盖 **20+ 协议 / 约 $68B TVL**（Aave、Uniswap、Balancer、Pendle、Sky、ENS、Euler…）。代价是三条硬约束：72 小时内归还到链上登记的 Asset Recovery Address；只覆盖"正在发生或迫在眉睫"的攻击；自己发起攻击再"救援"仍算黑帽。

**这意味着工具的第一产品不是"自动赚钱"，而是"自动确认这次行动受法律保护"。** 我们把这一步做成了工具：`safeharbor_registry` 直接读链上注册表，返回赏金比例、上限、身份要求、归还地址与覆盖链——**零凭据、零成本、一条 RPC 调用**。

**第三句：我们的护城河是"解释 + 验证"，不是"机房 + 硬件"。**

抢跑拼延迟，我们永远赢不了同机房的团队。但"把一笔交易的调用树翻译成人话""算出扣费后的净额并诚实地说不成立""在 fork 上验证损失数字与公开报道一致"——拼的是工具覆盖与语义质量。**这正是 152 个标准化 MCP 工具的地基。**

## 2. 现场演示：五分钟，一条链路，从"查协议"到"算出能救多少"

这套演示已经全部跑通，全部只读、零成本、不碰真实资金。

**第 1 幕：这个协议，允许我救吗？**（约 3 秒）

```
问：Aave 有没有登记白帽救援？条款是什么？
→ safeharbor_registry
→ registered: true
   protocolName: "Aave"
   bounty: 10%，上限 $1,000,000，身份要求 Named（KYC + 全球制裁筛查）
   覆盖 16 条链，含每条链的 assetRecoveryAddress
   资金必须 72 小时内归还到登记地址
```

反问一句，边界立刻清楚：

```
问：Vitalik 的地址登记了吗？
→ registered: false
→ "没有公开授权就不要动协议里的资金：只做只读复盘与披露。"
```

**第 2 幕：现在链上有多少协议是"可救"的？**（约 7 秒）

```
→ safeharbor_registry list
→ 23 个已登记协议：Aave 10%/$1M、Uniswap 10%/$2.25M、Balancer 10%/$1M、
   Pendle 10%/$2M、Sky 10%/$10M、ENS 10%/$250K、Euler 10%/$2.5M、
   Reserve 10%/$10M、1inch 10%/$500K …
```

**这一屏是整个叙事的证据**：这不是我们编的商业模型，是链上公开登记的 23 份合同。

**第 3 幕：一笔交易到底做了什么？**（约 2 秒）

```
→ tx_call_tree（交易 0xcdafd0d7…）
→ 40 条日志全部解码：WETH Transfer 1.33 ETH、Swap、Sync、Deposit…
→ assetFlows：每个地址每个代币的净变化，正的在前、负的在后
→ 节点不支持 debug_traceTransaction 时明确降级为回执日志，不装作有 trace
```

**第 4 幕：如果当时有这套工具，能救多少？**（约 38 秒）

```
→ fork_replay（同一笔交易）
→ 本机 anvil fork 到前一块，重放，status: success，gasUsed 754124
→ delta：付款方 −899454587283171 wei（转账 + gas），收款方 +26310455 wei
→ 全部发生在临时 fork 上，不进主网、不广播、不签名
```

**第 5 幕：这个"机会"能赚吗？**（约 3 秒）

```
→ arb_scan
→ 池 A 2238.70 USDC/WETH，池 B 2239.99，毛价差 5.77 bps
→ 扣两腿手续费 35 bps、扣 gas $0.14
→ 净额 −$146.30 → "不成立：扣除两腿手续费与 gas 后净额为负"
→ 并给出 $1 万 / $5 万 / $20 万 / $100 万 的敏感度表
```

**最后一幕才是记忆点**：一个号称"能赚钱"的工具，第一句话是"这笔不成立"。这比任何宣称都可信。

## 3. 同一套工具，翻面就是"自己的钱安不安全"

上面那套引擎翻过来，检查的是你自己：

| 工具 | 回答什么 | 成本 |
| --- | --- | --- |
| `approval_scan` | 我的地址都授权过谁，哪些是**无限授权** | 零（配了 Etherscan key 可扫全历史） |
| `allowance_check` | 某一个授权现在还能动我多少钱 | 零 |
| `nft_approval_check` | 有没有被 `setApprovalForAll` 授权整个集合（可一次转走全部 NFT） | 零 |
| `contract_posture` | 这个合约是不是代理、能不能被升级、owner 是谁、有没有 7702 委托 | 零 |
| `wallet_posture` | 余额、nonce、生效授权、无限授权数量一次看完 | 零 |

**实测到一个值得记住的细节**：查 Vitalik 的地址，`contract_posture` 返回 `isContract: true`、字节码 23 字节、并标出 **EIP-7702 委托**——他是个 EOA，但执行已经委托给了另一段代码。也就是说，"这是不是钱包"这个问题在 7702 之后已经没有简单答案了。**这种只有真跑一遍才会知道的东西，就是工具的说服力。**

## 4. 商业形态：三条收入线，都建立在"不碰用户资金"上

| 形态 | 卖给谁 | 收什么 | 为什么是我们 |
| --- | --- | --- | --- |
| **白帽哨兵 Watchtower** | 协议、金库、做市商 | 订阅 + 救援成功分成（行业惯例 10%） | 别人拼"第一个发现"，我们做"第一个解释清楚" |
| **复盘器 Post-mortem** | 投研、合规、受害者、审计 | 按次 / 订阅 | "这个地址是不是在跑机器人""我被抽了多少"是刚需，现有工具不给自然语言结论 |
| **自检 SaaS / 开源引流** | 个人与中小团队 | 开源免费 + 托管收费 | 152 个工具 MIT 开源，托管与告警收费 |

**刻意不做的三件事**：不做代客交易、不托管私钥、不提供攻击构造能力。工具只做检测与解释，救援交易只出**草案且必须人工确认**。这条边界写在工具输出里，不是写在宣传稿里。

## 5. 会被问到的五个问题，以及诚实答案

**问：这不就是在教人攻击吗？**
不。全部工具只读，或只在本机 fork 上跑。模式库只做检测不做生成；不提供私钥操作；不提供攻击构造。救援草案只对**已登记 Safe Harbor** 的协议生成，且必须人工确认。

**问：你怎么保证不误判？**
不保证。所以设计上就不自动提交：救援草案永远停在"草案"，正常的大额 swap 被误判最多浪费一次人工确认，不会造成二次损失。

**问：大安全公司 21 分钟就能响应，你凭什么？**
不与它们抢"第一个发现"。它们的优势是响应速度，我们的优势是把一次事件翻译成可复核的结论——这恰好是 agent 能做而规则引擎做不了的。

**问：数据供应商挂了怎么办？**
已经挂过一个：MEV 数据里最常被引用的 zeromev 现在返回 530。所以采集能力自建，多源冗余，且每个工具都把"没覆盖到什么"写在返回值里。

**问：要花多少钱？**
工具本身零成本可跑。可选的只有两个免费 key（Etherscan v2、The Graph）和一个归档 RPC 免费额度。**付费的数据源（Forta $399/月、Ironblocks $1,289/月、EigenPhi、Nansen/Arkham、Hypernative）全部留空**——见 [KEYS.md](./KEYS.md)。
