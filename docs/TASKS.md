## 3. S2：身份、授权与隐私

| 任务 | 实施内容 | 验收 |
| --- | --- | --- |
| T07 身份控制 | 初始注册、用途区分、账户关联、正常轮换、预登记恢复、控制分叉处理 | 非控制者更新失败；过期/重放更新失败；正常轮换保持历史验证 |
| T08 签署器 | 标准离线密钥、平台密钥引用、选定外部钱包/Safe 路径 | 不泄露 secret；实际签署和验证；不支持的签名格式明确失败 |
| T09 授权 | Biscuit 发放/收缩、已认证调用者绑定、资源/受众/动作/时间规则 | 子凭据不能扩权；不同调用者、受众、过期、重放均拒绝 |
| T10 状态 | 父级撤销、状态资源、观察时间、新鲜度、在线与历史验证 | 撤销父授权后子授权拒绝；状态不可用拒绝执行；历史结果保留时间边界 |
| T11 私有内容 | 认证加密、每版本密钥、凭证引用、公开字段控制、经确认的 SD-JWT disclosure profile | 未授权者不能从服务取得密钥；密文修改失败；错误 disclosure/对象绑定失败；secret 不出现在响应/日志/链上 payload |
| T12 存储 | 本地、私有 S3 兼容存储、选定公开 IPFS | 真实服务读写与完整回读校验；删除或停止服务后报告不可用 |

恢复阈值、等待期、挑战处理、当前状态来源和 `maxAge` 属于确认后的策略参数；必须在开始相关实现前写入任务配置。访问撤销的验证范围为后续服务访问，不能把已经交付的明文当作可收回数据。

| 任务 | 实施内容 | 验收 |

| T17 索引和最终性 | 索引查询、链上回查、区块哈希、最终性与状态缓存 | 索引缺失不宣称链上不存在；缓存过期不用于当前权限放行 |

本地开发链使用 Anvil 等真实 EVM 执行器部署官方合约，测试实际交易和链状态；这类结果单独标为本地链实验。公共测试网验收必须使用选定网络的实际部署，不能用本地结果替代。

多签支持按路径分别验收：Safe 直接调用、EOA delegated、合约签名 delegated 只有在目标部署接受相应签名格式并通过真实调用后才标记支持。

### 原生 Codex 验证要求

1. 只使用 Agent 创建的公开 Git 项目和用户指定的固定任务、上下文。
2. 使用已安装并配置的 Codex 原生控制器；关闭其原生文件与命令工具，只开放任务授权的 BCA 工具。
3. 运行实际 BCA HTTP 服务、真实 SQLite，读取控制器实际产生的会话文件。
4. 每个引用的 `event_id` 逐一在真实事件库定位，关联对应请求、工具响应、输入输出和链上回执。缺失条目立即报告，不能补写事件。
5. 区分模型自述、工具返回、控制器事件和链上记录；检查 Agent 没有通过未授权工具完成任务。
6. 实际运行正向链路及篡改、撤销、越权和必要服务不可用的失败链路；禁止使用视觉功能、mock 或伪造原生协议。
7. 在任务记录中填写实际客户端、精确模型标识（如控制器提供）、工具范围、验证命令、数据库/会话位置及实际结果。敏感材料不提交公开仓库。

公共契约由 A 维护，其他轨道通过 Handoff 提出修改；不直接修改其他轨道文件。A 完成共同入口与契约后再开展依赖它的并行工作。每条轨道固定一个 Agent、Worktree 和 Branch，开发、测试、文档、返修由同一 Worker 持续负责，提交并 push。

所有轨道结束后，单独集成 Agent 获得 `src/composition/`、必要入口导出、配置衔接和集成分支的写权限；领域错误交回原 Worker。共享文件的所有权转交记录在当时任务文件中，不能同时授予两个活动 Worker。主 Agent 在并行期间不编写业务代码，负责最终检查、提交和推送。
